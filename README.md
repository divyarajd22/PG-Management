## ✨ Features

### 👤 Two User Roles

| Role | Description |
|------|-------------|
| **Admin** | Pre-configured via application properties. Full management access. |
| **Guest** | Self-registered accounts. View-only dashboard for their PG details. |

### 🔐 Admin Capabilities
- **PG Management** — Register PG properties with name and city/area location
- **Room Category Master List** — Define room types (e.g., Single AC, Double Non-AC, Deluxe Suite)
- **Room Inventory** — Create rooms under a PG with category type and monthly rent
- **Member Assignment** — Assign/unassign guest users to specific rooms
- **Rent Tracking** — Toggle monthly rent paid/unpaid status per member

### 🏡 Guest Capabilities
- **Self-Registration** — Create an account with email, name, and phone
- **Personal Dashboard** — View assigned PG name, location, room number, and room type
- **Rent Status** — See current month's rent amount and payment status (Paid / Unpaid)
- **Pending State** — Clear messaging when no room has been assigned yet

### 🛡️ Security
- Stateless JWT-based authentication
- BCrypt password hashing
- Role-based access control (`ROLE_ADMIN`, `ROLE_GUEST`)
- CORS configuration for frontend integration

## 🚀 Getting Started

### 1. Database Setup

Create the database in SQL Server Management Studio or via command:

```sql
CREATE DATABASE pg_management;
```

> **Note:** Tables are auto-generated by Hibernate (`ddl-auto=update`). No manual table creation is required.

### 2. Backend Setup

```bash
# Navigate to the backend directory
cd pg-management-backend

# Configure database connection
# Edit src/main/resources/application.properties
# Update the following values to match your SQL Server instance:
#   spring.datasource.url
#   spring.datasource.username
#   spring.datasource.password
```

**application.properties** — key fields to update:
```properties
spring.datasource.url=jdbc:sqlserver://localhost:1433;databaseName=pg_management;encrypt=true;trustServerCertificate=true
spring.datasource.username=YOUR_SQL_USERNAME
spring.datasource.password=YOUR_SQL_PASSWORD
```

```bash
# Build and run the backend
./mvnw spring-boot:run
```

The backend API will start at **http://localhost:8080**

### 3. Frontend Setup

```bash
# Navigate to the frontend directory
cd pg-management-frontend

# Install dependencies
npm install

# Start the development server
npm run dev
```

The frontend will start at **http://localhost:5173**

## 📡 API Endpoints

### Authentication (`/api/auth`)

| Method | Endpoint | Description | Auth Required |
|--------|----------|-------------|:-------------:|
| `POST` | `/api/auth/login` | Authenticate user (admin or guest) | ❌ |
| `POST` | `/api/auth/register` | Register a new guest account | ❌ |

### Admin Operations (`/api/admin`) — Requires `ROLE_ADMIN`

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/admin/pgs` | List all PG properties |
| `POST` | `/api/admin/pgs` | Create a new PG |
| `DELETE` | `/api/admin/pgs/{id}` | Delete a PG and its rooms |
| `GET` | `/api/admin/categories` | List all room categories |
| `POST` | `/api/admin/categories` | Create a new room category |
| `DELETE` | `/api/admin/categories/{id}` | Delete a category and its rooms |
| `GET` | `/api/admin/rooms` | List all rooms |
| `POST` | `/api/admin/rooms` | Create a new room |
| `DELETE` | `/api/admin/rooms/{id}` | Delete a room |
| `GET` | `/api/admin/guests` | List all guest users |
| `POST` | `/api/admin/assign-room` | Assign a guest to a room |
| `POST` | `/api/admin/remove-member/{guestId}` | Remove guest from room |
| `POST` | `/api/admin/toggle-rent/{guestId}` | Toggle rent paid status |

### Guest Operations (`/api/guest`) — Requires `ROLE_GUEST`

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/guest/dashboard` | Get guest's PG, room, and rent details |

## 📖 User Guide

### Admin Workflow

```
1. Login ─► 2. Create PG ─► 3. Define Room Categories ─► 4. Add Rooms ─► 5. Assign Guests
```

1. **Login** with admin credentials (`admin@pg.com` / `admin123`)
2. Go to **PGs** tab → Add a PG property (name + location)
3. Go to **Room Categories** tab → Define room types (e.g., "Single AC", "Double Non-AC")
4. Go to **Rooms** tab → Create rooms by selecting a PG, category, room number, and rent
5. Go to **PG Members** tab → Click **Assign Room** on any registered guest → Select a room
6. Toggle the rent **PAID / UNPAID** badge to track monthly payments

### Guest Workflow

```
1. Register ─► 2. Login ─► 3. View Dashboard (after admin assigns a room)
```

1. Click **Sign Up** on the login page → Fill in name, email, phone, password
2. **Login** with guest credentials
3. If a room has been assigned → See PG name, location, room details, and rent status
4. If no room assigned yet → See a "Pending PG Allocation" notice
